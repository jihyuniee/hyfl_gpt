실제 데이터 연결

값과 열 이름을 함께 알려주세요.

분석에 사용할 실제 데이터 파일을 올려주세요. 개인 정보가 없는 공개 데이터를 사용해요.

아직 연결한 데이터가 없어요.

API 응답 붙여넣기 · 기상·환경·교통 등

API로 받은 JSON 응답 본문을 연결합니다. 요청 URL·인증키는 붙여넣지 마세요. 이 입력은 연결 버튼을 누르기 전까지 프로젝트에 저장되지 않습니다.

받아 둔 응답으로 필터·집계·그래프를 만들 수 있습니다. 실시간 갱신 기능은 별도 API 연결이 필요하며, 이 기능은 요청을 보내거나 다음 페이지를 자동 수집하지 않습니다.
