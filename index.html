프로젝트 자료

파일을 넣거나 필요한 자료를 찾으세요.

활동지 내용을 다시 입력할 필요가 없습니다. 자료와 요청만으로 시작하세요.

연결한 자료

합계 320KB · 최대 8개. 첨부하면 전체 데이터로 표·그래프를 만듭니다.

API로 받은 JSON 응답 붙여넣기

받아 둔 응답 본문을 넣으세요. 인증키나 요청 URL은 넣지 마세요.

저장된 응답을 사용합니다. 새로고침으로 최신 자료를 받거나 다음 페이지를 자동 수집하지 않습니다.

작업 이름·목표 메모 (선택)

공공데이터 찾기

공식 사이트에서 자료를 내려받아 첨부하세요. AI에게 검색어·필요한 열·API 요청 방법을 물어볼 수도 있어요.

KOSIS 국가통계포털 ↗공공데이터포털 ↗서울 열린데이터광장 ↗

위 링크는 공식 사이트를 엽니다. 현재 스튜디오에 KOSIS MCP 자동 조회가 연결되어 있지는 않습니다.

저장·내보내기

활동지는 기존 구글 클래스룸에서 작성하세요. 이곳에 별도로 기록할 내용은 없습니다.
