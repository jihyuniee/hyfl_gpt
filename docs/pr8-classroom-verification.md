# 학생 스튜디오 검증 결과

검증 기준: PR #8 da0399727cedfd1d92595477811fd5182ae15c45 및 이 커밋 위의 안내 수정·회귀 테스트.

## 결과
조건부 수업 적용. 자동 검증 86개, JS 검사, 정적 빌드 통과. 유료 AI와 실제 팀 로그인·저장 재접속은 미검증이므로 전면 운영 승인 근거로 사용하지 않는다.

- CSV 250행(마지막 행 999, 첫 값 0)과 JSON 15행, 기존 HTML 전체가 두 작업의 /api/ai 요청에 그대로 포함됨을 실제 클라이언트 코드+대체 DOM/전송 어댑터로 추가 검증했다. 기존 코드는 응답 후에도 유지되며 명시적으로 적용할 때 이전 버전으로 보관된다. 모델 응답은 가상 응답으로서 실제 유료 모델 품질 검증이 아니다.
- 기존 실행 테스트에서 전체 행 통계, 한글·인용부호·줄바꿈, 0·결측, JSON API 응답과 오류, HTML 내보내기·재가져오기와 첨부 원문 보존이 통과했다. 표는 최대 100행, 그래프는 최대 120개 표시 제한을 안내한다. 집계는 전체 대상 행 기준이다. 이 실행 테스트는 VM/DOM 어댑터이며 실제 브라우저 실행 성공과 구분한다.
- 브라우저에서 기존 231ea40 배포의 로그인 화면→둘러보기→작업 선택→자료 화면까지 확인했다. 파일 선택 호출이 두 번 완료되지 않아 실제 파일 첨부 이후 화면과 독립 HTML 실행은 확인하지 못했다. 앱의 업로드 오류로 단정하지 않는다. 이후 최신 커밋의 넓은 첫 화면은 이번 브라우저 검증 범위가 아니다.
- 기준 231ea40의 Vercel commit status success와 PR 봇 Ready를 확인했다. 이번 수정 커밋 배포 완료 여부는 별도로 확인해야 한다.

## 안내 수정
‘이 작업 요청하기’를 ‘요청 초안 열기’로 변경했다. AI 비용은 전송 시 발생한다. AI가 항상 원문 전체를 읽는 것으로 오해하지 않도록 현재 HTML 전체, 데이터 구조·일부 행·전체 통계, 작은 자료의 전체 행 전달과 실행 시 전체 원문 사용을 구분했다. 서버의 작은 자료 기준은 200행 이하이면서 행 JSON 12,000자 이하이며 입력 예산에 따라 전체 행이 제외될 수 있다. 원자료 첨부는 합계 320KB·8개 제한이다.
