# 인탐 스튜디오: 학교 제공 AI로 직접 작업하기

최신 팀별 자료·작업 분리 변경과 69개 테스트 결과는 [팀별 데이터 분리](team-isolation.md)를 참고하세요. 아래 브라우저 기록 중 둘러보기의 재접속 복원은 이 변경 이전 동작이며, 현재 둘러보기는 새로고침할 때 초기화됩니다.

목적은 학생들이 학교가 제공하는 GPT·Claude 이용 환경에서 데이터 분석·시각화·웹앱 제작을 쉽게 수행하도록 돕는 것입니다. 기록과 성찰은 배부된 활동지에서 하며 앱에 중복 입력하지 않습니다.

## 바뀐 학생 흐름

1. 작업실에서 자료를 첨부합니다. 프로젝트 맥락 양식을 먼저 채울 필요가 없습니다.
2. 표 자료는 전체 파일을 읽어 표·그래프를 즉시 생성합니다. 이 단계에는 AI 사용량이 들지 않습니다.
3. 「표·그래프 만들기」「데이터 비교·분석」「웹앱 만들기」를 선택하거나 원하는 작업을 직접 입력합니다. 초안 선택과 실제 AI 전송은 구분합니다.
4. 첫 AI 결과는 자동 실행합니다. 기존 결과의 수정은 먼저 미리 보고 적용하며 이전 버전과 전체 자료를 유지합니다.
5. HTML·프로젝트 백업·보관된 실제 대화를 내려받습니다. 수동 체크리스트·성찰·대표 AI 기록 입력은 없습니다.

기존 프로젝트의 brief·checks·records 필드는 삭제하지 않습니다. 서버 저장과 백업에서 그대로 보존되며 이전 백업도 가져올 수 있습니다.

## 수업에서 학생에게 시킬 일

활동지 STEP 2-3에서 정한 기능 하나를 이 앱에서 실제로 만들고 눌러보는 데 집중합니다. 첫 화면에는 ① 자료 넣기 ② 만들거나 고칠 기능 말하기 ③ 눌러서 실행해 보기만 우선 보이게 합니다. AI 선택·질문 모드와 자료·저장·도움말은 접어 두되 기존 기능은 유지합니다.

- 의류수거함 CSV: “동을 선택하면 의류수거함 위치 목록이 나오게 만들어 줘.” 주소만 있다면 목록부터 시작하며 지도를 위해 필요한 좌표·지도 연결은 별도로 확인합니다.
- 연도별 통계 CSV: “연도를 선택하면 해당 연도의 값이 나오게 만들어 줘.”
- 기상 JSON: “같은 발표 회차·항목·격자로 예보 대상 시각별 기온 그래프를 만들어 줘.”
- 실행 후: 조건을 두 개 이상 바꾸고 원자료의 행 하나와 결과를 비교합니다. 안 맞으면 무엇을 눌렀고 무엇이 나왔는지 요청창에 써서 고칩니다.
- 요청과 확인한 결과는 기존 활동지 STEP 2-4·STEP 4에 적습니다. 스튜디오에 같은 내용을 다시 기록할 필요가 없습니다.

## 실제 데이터 활용

- 작은 표 자료(200행·행 JSON 12,000자 이하)는 전체 행과 열 순서를 AI 맥락에 제공합니다. 13행 자료라면 8행 표본에 그치지 않습니다.
- 큰 표 자료는 전체 행의 기초 통계와 구조·샘플을 제공합니다. 입력 한도가 부족하면 부가적인 전체 행 맥락부터 줄이고 최신 코드 전체는 유지합니다.
- 빠른 그래프는 가로축·세로축·형태를 바꾸어 실제 값으로 계산합니다. 그래프 120점·표 100행 표시 제한과 전체 범위를 밝히고 원문 전체를 HTML에 포함합니다.
- 기상 category·발표 회차·격자·대상일, 대기 측정 시각, KOSIS 항목·단위·지역을 필터로 구분합니다. 범주형 강수나 결측을 0으로 변환하지 않습니다. 서로 다른 항목·단위를 섞은 전체 통계를 AI에 제공하지 않습니다.
- 출력은 원자료 단위와 해석을 확인해야 하며 자동 기초 통계가 인과관계나 서비스의 안전성을 입증하지 않습니다.

## 연결 범위

GPT·Claude는 기존 서버의 설정된 모델과 팀별 이용 한도로 호출합니다. 학생에게 제공사 키를 나눠 주지 않습니다. 학생 화면에는 실제 설정된 모델 ID를 표시합니다.

현재 KOSIS MCP·웹 검색·기관 API 자동 조회는 연결되어 있지 않습니다. 공식 사이트 링크와 자료 확보 요청 초안, 파일·JSON 응답 연결을 제공합니다. 고급 AI 모델 사용과 외부 데이터 도구 연동을 혼동해 이미 조회했다고 표시하지 않습니다. 실시간 KOSIS 활용에는 실제 데이터 도구와 서버 인증 연결을 별도로 준비해야 합니다.

## 검증

- 자동화 테스트 60개 통과. 기존 인증·사용량·저장 충돌·CSV·NEIS·API 회귀 검증 포함.
- 새 검증: 전체 데이터 통계·0과 결측 구분, 작은 자료 전체 전달·입력 한도 처리, 빠른 그래프 실제 코드 실행·표시 제한·마지막 행 보존·HTML 문자열 주입 경계, 기상 항목·회차 필터, 실제 대화 내보내기.
- 구문 검사·빌드·diff 검사 통과.
- 예시 코드 실행 테스트는 Node VM과 제한된 DOM 어댑터를 사용합니다. 유료 모델 호출은 별도 확인 항목입니다. 아래는 배포 브라우저에서 직접 확인한 범위입니다.


### 배포 브라우저 확인 (2026-10-26)

보호된 Preview에 정상 로그인한 뒤 둘러보기의 격리된 테스트 작업에서 확인했습니다. 인증정보·실제 학생 자료는 사용하지 않았습니다. 모든 수치는 실제 구조를 따른 가상 검증값입니다.

- CP949 한글 CSV 13행 첨부, 전체 행 평균 0.9·최소 0.6·최대 1.2, 축 선택·막대 전환, HTML 다운로드·재가져오기·실행 및 브라우저 재접속 후 데이터 복원을 확인했습니다.
- 기상 예보 48행, 관측 12행, 환경 12행, 포털 12행, 서울 12행의 행 수·경로와 페이지 누락 안내를 확인했습니다.
- 배포 Chromium에서 미리보기 문서 계산 후 화면이 흰색으로 남는 현상이 재현되어, 갱신 시 sandbox 속성을 유지한 새 iframe을 생성하도록 수정했습니다. 수정 배포에서 작업실 내 갱신·자료 화면에서 전환·HTML 재가져오기 모두 새로고침 없이 표시되는 것을 재확인했습니다.
- 배포 브라우저에서 발표 회차 변경 시 평균 -0.5→9.5℃, 범주형 강수 4건의 숫자 제외, PM10의 0 포함·결측 제외 평균 5μg/m³, 마지막 시간 평균 80μg/m³, 오존 0.025ppm, 실황 관측값 구분을 확인했습니다.
- 빠른 그래프에 예보/실황 구분, 발표/예보 대상/측정 시각과 알려진 항목 단위를 표시합니다. SKY·PTY·LGT 분류 코드에는 평균과 수치 그래프를 만들지 않습니다.
- JSON 응답 본문 붙여넣기에서 단일 item과 0값을 인식했습니다. 7개 자료 총 110행을 담은 HTML과 프로젝트 백업을 실제 다운로드했고, 파일의 원문 전체가 업로드 전과 일치함을 비교했습니다. HTML을 다시 가져와 실행한 결과도 확인했습니다.
- 실제 유료 AI 검증을 위해 1반 테스트팀 안전 로그인을 시도했으나 서버가 “팀 이름과 비밀번호를 확인해주세요”로 거절했습니다. 비밀번호는 모델에 노출되지 않았습니다. 실제 GPT/Claude 유료 응답과 학생 팀 서버 저장은 미검증입니다.
- 다운로드한 HTML의 별도 브라우저 파일 실행, KOSIS/MCP·실시간 기관 API 연결은 미검증입니다. 후자의 연결은 현재 구현되어 있지 않습니다.
- 판정: 파일 기반 자료 분석과 시각화 실습에는 사용할 수 있습니다. 유료 AI 제공이라는 핵심 목적의 전면 수업 사용은 정상 테스트팀 로그인→실제 모델 요청→팀 저장 재접속 확인과 운영 배포까지 마친 뒤 판단해야 합니다. 현재 PR Preview만 갱신되었고 main은 병합하지 않았습니다.

단위·시각 안내의 기준: [기상청 단기예보 API](https://www.data.go.kr/data/15084084/openapi.do), [기상청 API허브](https://apihub.kma.go.kr/apiList.do?seqApi=10), [한국환경공단](https://www.keco.or.kr/web/index.do), [에어코리아](https://www.airkorea.or.kr/web/main.do). 첨부 자료가 이 API와 다른 명세라면 원자료 설명을 우선 확인해야 합니다.


## Open API 도움 버튼

자료 첨부 영역의 「인증키를 받았는데 다음에 어떻게 하죠?」에서 첫 요청 준비·요청 오류·응답 해석·응답으로 앱 만들기 중 필요한 작업을 고릅니다. 「질문 초안 넣기」는 앞의 세 작업을 질문·해석 모드, 마지막 작업을 만들기 모드로 열며 학생이 대괄호를 고친 뒤 전송합니다. 예시를 다른 생성형 AI에 복사할 수도 있습니다. 초안 삽입·복사는 AI를 호출하거나 팀 자료를 변경하지 않고, 이미 작성한 요청을 바꾸기 전에는 확인합니다.

공식 문서의 요청 주소·인자 표 등 필요한 부분을 키 없이 붙이도록 안내합니다. 현재 AI는 URL만으로 문서를 읽거나 기관 API를 직접 호출할 도구가 없습니다. 실제 호출은 공식 실행 화면 등에서 하고, 받은 CSV/JSON 파일 또는 JSON 본문을 스튜디오에 연결합니다. XML은 자동 행 인식을 지원하지 않으며, JSON 지원 확인 또는 TXT 원문 활용을 안내합니다. 실제 인증키·개인정보를 입력하거나 HTML에 저장하도록 요구하지 않습니다. 데이터 갱신에는 새 응답을 다시 연결해야 합니다.

이 변경의 자동 검증은 버튼의 작업 모드·초안 전달, 사용량 차감 전 무호출, 기존 초안 보존과 복사 범위에 대한 실제 클라이언트 실행을 포함합니다. 실제 AI 답변과 기관 API 호출 성공을 검증했다는 의미는 아닙니다.


## 학생 작업 화면 점검 (2026-10-26)

의류수거함 형태의 가상 위치 자료로 처음 사용하는 학생의 흐름을 점검했습니다. 기존 배포에서는 355px 대화창에 자료·AI 선택·대화·입력을 모두 배치해, AI 선택 영역을 열면 입력 상태와 활동지 안내가 패널 아래로 잘렸습니다. 위치 자료에서 연번을 가로축, 위도를 세로축으로 자동 선택해 위도 평균을 첫 결과로 보여주는 문제도 확인했습니다.

- 자료 연결은 작업실 위의 공통 영역으로 이동합니다. 함께 보기·대화 넓게·결과 넓게를 전환할 수 있으며 코드·자료·대화·초안은 유지합니다. 기본 글자와 버튼을 키우고 입력·대화를 위한 높이를 확보합니다. 짧은 화면에서는 스크롤로 모든 조작에 접근할 수 있게 합니다.
- 자료·저장·내보내기·이전 버전·도움말을 메뉴에 바로 표시하고, 요청 예시와 HTML 내려받기를 글자가 있는 버튼으로 제공합니다. 첨부 자료 이름을 누르면 자료 정보를 보여주며 현재 앱을 자동으로 덮어쓰지 않습니다.
- 좌표·번호만 있는 자료는 표를 기본으로 보여줍니다. 행정동·지역·연도 등의 열이 있고 값이 2~30개이면 전체/특정 값을 고르는 필터를 제공합니다. 원문 전체는 보존하며 기상·환경의 항목/시각 필터는 유지합니다.
- 적용 전 AI 수정안이 있으면 다음 요청을 보내기 전에 적용 또는 되돌리기를 안내합니다. 새 코드가 도착하면 결과 보기를 열고, 이전 코드는 적용 시 버전으로 남깁니다. JSON 응답 연결 후 작업실로 돌아와 결과를 볼 수 있습니다.
- 자동 검증: 76개 테스트, 구문 검사·빌드·diff 검사 통과. 위치 표의 전체 6행→동별 2행→전체 6행, 연도 필터의 0값, 보기 전환/팀 전환과 초안 보존, 수정안 보존을 포함합니다. 배포 브라우저 후속 결과는 PR 검증란에 기록합니다.

이 UI 점검은 실제 지도 서비스의 위치 정확도나 AI 모델 답변 품질을 검증한 것이 아닙니다. 실제 팀의 유료 AI 요청과 서버 저장 재접속, 실제 iPad에서의 터치·가상 키보드 사용은 별도 확인이 필요합니다. 기관 API 직접 호출은 현재 범위에 포함되지 않습니다.


## 최신 화면: 대화 중심 작업실

학생이 각자 진행하는 프로젝트를 계속 이어 가도록 ChatGPT와 비슷한 대화/결과 배치로 정리했습니다. 위쪽의 단계 안내·자료 영역·큰 AI 설정을 제거하고, 아래의 작은 입력창과 + 파일 메뉴로 모았습니다. 입력창은 내용에 따라 늘어나고 Enter로 전송, Shift+Enter로 줄바꿈합니다. 새 작업은 대화 화면에서 시작하며 웹앱 코드가 오거나 HTML을 가져오면 결과를 나란히 엽니다.

사이드바는 접고 펼칠 수 있습니다. 대화/결과의 경계는 마우스·터치로 끌거나 방향키로 조절하며 두 번 클릭 또는 Enter로 초기화합니다. 보기 비율과 사이드바 설정만 기기에 보관하고 팀 자료·초안은 섞지 않습니다. 대화와 결과를 각각 스크롤하며 전체 페이지와 입력창이 함께 밀리지 않도록 높이를 구성했습니다. 태블릿의 좁은 화면은 대화/결과 전환으로 제공합니다.

+ 메뉴와 파일 놓기로 CSV·TSV·JSON·TXT 데이터 또는 HTML 앱을 가져옵니다. HTML은 한 번에 한 개, 데이터는 기존 합계 용량 한도 안에서 받습니다. 기존 파일 분석·API 응답·전체 원문 내보내기·버전·팀 분리는 유지합니다. 자동 검증 78개에는 경계 조절의 상하한/키보드, 보기 설정에 팀 데이터가 저장되지 않는 점, HTML 가져오기와 혼합 파일 묶음 보호가 포함됩니다.

교사 로그인 확인 중 ADMIN_PASSWORD가 Production에만 등록된 것을 확인해 값을 조회·교체하지 않고 Preview 적용 범위를 추가했습니다. 환경 변경 후 새 Preview 배포에 설정을 반영했습니다. 실비밀번호 입력 로그인은 별도 확인 범위입니다.
