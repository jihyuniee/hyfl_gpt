# 인탐 스튜디오 · 데이터 웹앱 작업실

인공지능 원리탐구 2학기 프로젝트를 위한 팀 공통 코딩 환경입니다. 기존에 찾은 데이터와 만들던 HTML을 가져와, 같은 AI 환경에서 구현·수정·실행·검증·기록을 이어갑니다.

- 운영 주소: https://hyfl-gpt.vercel.app/
- 교과서: https://jihyuniee.github.io/hyfl-ai-lab/data-project/
- 기본 실습: https://jihyuniee.github.io/hyfl-ai-lab/data-lab/
- 설계와 교과 연계: [docs/semester2-plan.md](docs/semester2-plan.md)

## 학생의 사용 흐름

1. 반·팀·비밀번호로 로그인합니다. 기존 팀은 교사가 새 비밀번호를 한 번 설정한 뒤 이용합니다. 새 팀은 등록 후 교사 승인을 받습니다.
2. `만들기 → HTML 가져오기`에서 기존 HTML을 엽니다. `프로젝트 맥락 → 데이터 파일 추가`에서 확보한 CSV·TSV·JSON·TXT와 짧은 프로젝트 맥락을 연결합니다. 출처 주소만 적으면 데이터 파일이 자동으로 연결되지는 않습니다.
3. `만들기 / 수정 / 오류 해결 / 이해하기` 중 필요한 작업을 선택합니다. 현재 코드와 데이터 구조가 요청에 함께 전달됩니다. 시작이 막히면 `수업 가이드 → 지금 필요한 도움`에서 활동지 단계에 맞는 요청 초안을 열고 팀의 내용으로 바꿉니다. 초안 선택만으로 AI를 호출하지 않으며, `AI에게 요청`을 눌러야 전송됩니다.
4. 제안 내용과 확인 사항을 읽고 `변경 내용 적용`을 누릅니다. 오른쪽에서 실제 입력과 결과를 확인합니다. 이전 코드는 `이전 버전`에서 복원할 수 있습니다.
5. 답변의 `대표 기록에 담기`를 누르고, `검증과 기록`에서 직접 확인한 사실과 팀의 판단을 적습니다. 기록 횟수와 범위는 배부된 활동지와 교사의 수업 안내를 따릅니다. 사이트의 기록 기능은 활동지 작성을 돕는 보조 도구입니다.
6. 전체 데이터가 포함된 HTML과 필요한 기록을 내려받습니다. 최종 제출은 기존 구글 클래스룸의 활동지와 웹앱이며, 이 사이트에서 별도 제출하지 않습니다.

로그인 없이 둘러보기에서는 실제 파일 가져오기·편집·미리보기·백업·내보내기를 사용할 수 있습니다. 작업은 해당 브라우저에만 남고 AI 요청은 실행하지 않습니다.

## 운영 설정

외부 패키지나 프런트 빌드 프레임워크 없이 Node.js 24와 Vercel Functions를 사용합니다. 기존 Vercel 프로젝트의 GitHub 연동을 유지합니다.

### Vercel 환경 변수

| 이름 | 용도 |
| --- | --- |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | 기존 Upstash/Vercel KV REST 저장소. 없으면 인증·저장·AI를 열지 않습니다. |
| `OPENAI_KEY` | 교사 OpenAI API 키. 브라우저에 전달하지 않습니다. |
| `CLAUDE_KEY` | 교사 Anthropic API 키. 브라우저에 전달하지 않습니다. |
| `ADMIN_PASSWORD` | 새 교사 로그인 비밀번호. `TEACHER_PASSWORD` 별칭도 지원합니다. 소스·학생 화면에 공개하지 않습니다. |
| `SESSION_SECRET` | 선택: 전용 세션 서명 비밀. 미설정 시 KV 토큰에서 별도 용도로 파생합니다. |
| `APP_ORIGIN` | 선택: 고정 허용 출처. 미설정 시 실제 요청 호스트와 Origin을 비교합니다. 프로덕션 주소를 지정하면 다른 미리보기 주소의 변경 요청은 거절됩니다. |

환경 변수를 변경한 뒤 새로 배포해야 반영됩니다. 키나 비밀번호를 코드·활동지·공개 HTML에 붙여넣지 않습니다. 교사 비밀번호가 설정되지 않은 경우 교사 관리와 신규 팀 승인·기존 팀 비밀번호 전환이 잠깁니다. 과거 공개 HTML에 들어 있던 교사 비밀번호는 사용하지 않습니다.

### 기본 운영값

- GPT와 Claude의 사용 가능 여부, 기본 AI, 요청 일시 중지, 팀 승인·중지를 교사 화면에서 관리합니다.
- 기본 요청 한도는 팀별 하루 12회, 전체 하루 250회입니다. 개별 팀 한도도 지정할 수 있습니다.
- 기본 추정 비용 한도는 팀별 하루 $2, 전체 하루 $25, 전체 월 $150입니다. 실제 수업 규모·남은 잔액·계정 한도에 맞춰 조정합니다.
- 한국 시간의 날짜·월을 기준으로 집계합니다. 호출 전 최대 예상액을 원자적으로 예약해 동시 요청으로 한도를 넘는 상황을 막습니다.
- 표시 비용은 이 사이트가 기록한 토큰과 서버 가격표의 추정치입니다. 실제 잔액, 다른 도구의 사용, 크레딧 만료일, 과금 정책은 API 제공사의 대시보드에서 별도로 확인합니다.
- 팀당 유료 요청 하나만 동시에 실행합니다. 오류 응답·중단에도 사용된 것으로 확인되는 토큰은 정산하며, 사용량을 확인할 수 없는 요청은 보수적으로 계산합니다.

과거 Vercel 배포의 고유 URL은 최신 코드로 바뀌지 않습니다. 수업 공개 전 Deployment Protection이 이전 배포 URL에도 적용되는지 확인하고, 공개된 예전 AI 경로가 있으면 접근을 차단하거나 기존 키를 폐기하고 새 키를 새 배포에만 연결합니다. 새 사이트의 한도는 다른 앱이나 과거 코드의 API 호출까지 통제하지 않습니다.

현재 서버 모델 목록과 단가는 `lib/server/common.mjs`에 있습니다. 새 모델을 추가하려면 공식 API의 모델 ID, 구조화 응답 방식, 가격을 함께 확인해 서버 목록과 테스트를 갱신합니다. 다른 모델로 조용히 대체하지 않습니다.

## 보존·용량·검증

기존 `teams` 원본은 유지합니다. 새 계정은 별도 `hyfl:studio:v2:teams` 저장소로 한 번만 가져오며, 이후 예전 배포의 팀 변경이 새 계정에 영향을 주지 않습니다. 과거 API가 비밀번호를 응답에 포함했으므로, 기존 비밀번호만 있는 팀은 교사가 새 비밀번호를 설정한 뒤 로그인할 수 있습니다. 재설정은 해시만 저장하고 기존 비밀번호와 로그인 세션을 무효화합니다. 한글 팀명은 별도의 안정적인 해시 ID로 구분합니다. 기존 대화·진행 데이터의 원본 키는 삭제하지 않으며, 충돌 가능성이 있는 예전 키를 새 프로젝트에 임의로 연결하지 않습니다.

새 프로젝트는 팀별 이름 공간에 저장합니다. 저장 시 revision을 비교해 다른 기기의 변경을 덮어쓰지 않습니다. 같은 팀에서 여러 기기를 쓰면 한 기기에서 코드를 수정하고, 충돌 시 현재 작업을 백업한 뒤 최신 작업을 불러오는 방식을 권합니다.

브라우저 기준 HTML 120KB, 전체 첨부 데이터 320KB, 프로젝트 전체 800KB, 데이터 파일 8개, 최근 코드 버전 6개, 최근 대화 36개를 지원합니다. 전체 용량이 차면 오래된 코드 버전과 대화부터 줄이며 현재 데이터·대표 기록을 임의로 삭제하지 않습니다. XLSX/PDF는 CSV·JSON·TXT로 변환해 사용합니다. 큰 자료는 수업에서 사용할 열·행을 명확히 추려 연결합니다.

미리보기는 `allow-scripts`만 허용하는 별도 sandbox iframe에서 실행합니다. 부모 페이지의 쿠키·저장소와 분리하며, 제한된 실행 오류만 가져옵니다. 오류를 발견해도 유료 AI를 자동 호출하지 않습니다. 코드 버전 복원은 HTML만 복원합니다. 데이터·대표 기록까지 보관하려면 전체 프로젝트 백업을 내려받습니다.

AI에는 데이터 구조와 일부 샘플을 전달할 수 있지만, 실행 시에는 `window.HYFL_DATASETS`에서 파일 전체를 읽습니다. 내보내는 HTML에도 전체 데이터가 들어갑니다. 샘플 행을 전체 데이터처럼 사용하지 않도록 모델 지침에 명시했습니다. 계산의 정확성이나 원자료 대조, 다른 팀의 사용 테스트를 대신 완료한 것으로 표시하지 않습니다.

NEIS 식단 JSON은 `mealServiceDietInfo` 안의 실제 `row` 배열에서 행 수·열·샘플을 읽습니다. 응답의 `list_total_count`와 업로드한 파일 안의 행 수는 구분합니다. 자료를 자동 수집하거나 다음 페이지를 추가로 내려받는 기능은 아니므로, 비교에 필요한 기간과 학교의 데이터가 파일에 모두 포함됐는지 확인합니다.

## 개발과 확인

```sh
npm run dev
npm run check
npm test
npm run build
```

`npm run dev`는 `.env.local`이 있으면 읽고 실제 API를 실행합니다. 인증·저장·AI를 흉내 내는 메모리 저장소는 운영 코드에 없습니다. 개발 시 환경 변수가 없으면 공개 화면과 둘러보기를 확인할 수 있습니다. 테스트의 메모리 저장소와 제공사 응답은 테스트 안에서만 주입합니다.

공개 빌드는 `dist/`에 HTML·CSS·브라우저 모듈만 복사합니다. 서버 코드, 문서, 테스트, 환경 변수는 정적 파일로 제공하지 않습니다. 기존 `/api/chat`, `/api/stream`, `/api/teams`, `/api/conversations`는 410으로 종료하며 새 서버 인증을 우회하는 경로로 남기지 않습니다.

의미 있는 검증 범위는 인증과 별팀 접근 방지, 한글 팀 구분, 레거시 저장 형식 이행, 원자적 사용 한도, 저장 충돌, 잘린 AI 출력 차단, CSV 인용·줄바꿈 처리, 전체 데이터 내보내기와 HTML 주입 경계입니다. 실제 제공사 잔액·키 권한·모델 응답은 배포 환경의 정상 팀 요청으로 별도 확인해야 합니다.

## 급식 이외의 공공 API 프로젝트

`프로젝트 맥락 → API 응답 붙여넣기`에서 기상·환경·교통 등 공공 API의 **JSON 응답 본문**을 데이터로 연결할 수 있습니다. 기존 CSV·NEIS·HTML 가져오기 기능도 그대로 사용합니다. 기상청 `response.body.items.item`, 환경 API의 `response.body.items`, 공공데이터포털 `data`, 서울시 `서비스명.row` 형식을 인식하며 실제 행 경로를 표시합니다. 알려진 전체 건수가 현재 응답보다 크면 페이지 누락 가능성을 안내합니다. 다른 구조는 확인이 필요하며 모든 기관의 API 형식을 자동 인식한다고 보장하지 않습니다.

이 기능은 API 요청 대행이나 실시간 자동 갱신이 아닙니다. 학생이 이미 받은 응답을 전체 데이터로 연결해 HTML에 포함합니다. JSON 대신 XML을 받았다면 공식 문서에서 JSON 요청 옵션을 확인하세요. XML은 TXT로 구조를 확인할 수 있으나 자동 표 변환은 지원하지 않습니다.

`수업 가이드`의 「API 응답으로 기능 만들기」·「실시간 API 연결 점검하기」에서 AI 요청 초안을 선택할 수 있습니다. 초안을 선택하는 것만으로 유료 AI를 호출하지 않습니다. 실제 행 경로·오류 코드·페이지 범위와 기상 항목/단위/시각 구분을 지침에 포함합니다.

인증키는 붙여넣지 않습니다. 알려진 인증 필드가 있는 붙여넣기 응답은 거절하지만, 임의의 필드나 문자열에 숨은 키를 모두 탐지하는 기능은 아닙니다. 파일·기존 코드·출처 주소에도 키가 없는지 직접 확인해야 합니다. 키가 필요한 실시간 조회는 교사가 관리하는 별도 서버와 설정이 있어야 하며, 이 변경은 범용 프록시나 인증키 저장 기능을 추가하지 않습니다. [학생 지도 예시와 API 확인 순서](docs/public-api-projects.md)를 참고하세요.

검증 범위와 배포 브라우저에서 남은 확인 사항은 [2026-10-26 PR #7 검증 보고서](docs/public-api-verification-20261026.md)를 참고하세요. 실제 구조의 가상 JSON·검증용 HTML·프로젝트 백업은 `node scripts/prepare-public-api-check.mjs /tmp/hyfl-api-check`로 만들 수 있습니다.
